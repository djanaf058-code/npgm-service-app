# NPGM Service — титульный экран (hero), редизайн

**Дата:** 2026-05-22
**Статус:** реализовано (Приоритет 1). Приоритет 2 (единый визуальный язык) — отдельной задачей.

## Контекст
Редизайн только визуала титульной страницы B2B-приложения для подрядчиков
горнодобычи. Аудитория: операторы (телефон, солнце, перчатки) и менеджеры
(десктоп). Рынки КСА/ОАЭ/СНГ, языки интерфейса EN/RU.

## Решения (утверждено пользователем)
- **Палитра:** фирменные цвета логотипа — индиго `#383080` (бренд/фон),
  красный `#e01848` (только CTA/акценты/критичные статусы).
- **Тон:** тёмный premium.
- **Фон:** реальное фото СЗМ на закате (КСА), `public/hero-szm-sunset.jpg`.
- **Объём:** только первый экран (`100svh`, без скролла). Блок «что умеет»
  и футер не добавляются.
- **Контент:** по центру — название `NPGM Service` + одна строка описания,
  под ними две кнопки.
- **Описание (RU):** «Обслуживание и ремонт парка горной техники — в одном
  приложении». **(EN):** "Maintenance and service for your mining fleet — in one app".

## Композиция hero
- Фон: `next/image` `fill` + `object-cover`, `objectPosition: 50% 45%`, `priority`.
- Скрим (читаемость под солнцем): радиальный индиго-градиент с притемнением
  к центру (где заголовок) + линейный к низу. Базовый тон `rgba(28,22,64,…)`.
- Навигация: знак-логотип (`Logo variant="mark"`) + белый текст «NPGM Service»
  слева; `LocaleSwitcher theme="dark"` (стеклянный) справа.
- Центр: H1 `clamp(40px,9vw,76px)` IBM Plex Sans 700; подзаголовок
  `clamp(16px,2.4vw,21px)` Inter; кнопки.
- Кнопки: primary красная `#e01848` (≥52px), secondary стеклянная с белой
  обводкой; на мобиле — в столбик, full-width; tap-target ≥44px.

## Изменённые файлы
- `src/app/page.tsx` — переписан hero (фото + скрим + центр-контент).
- `src/components/AuthAwareButtons.tsx` — добавлен вариант `hero`
  (бренд-кнопки, i18n; сохранена auth-aware логика: вошедший видит «В приложение»).
- `src/components/i18n/LocaleSwitcher.tsx` — добавлен проп `theme: 'light' | 'dark'`

  `landing.cta_dashboard`.
- `public/hero-szm-sunset.jpg` — фон (переименовано в нижний регистр).
